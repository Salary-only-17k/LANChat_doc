# 产品概述  
LANChat是一款专为高保密需求场景设计的本地化大语言模型部署平台，搭载NVIDIA Jetson AGX Orin（64GB）边缘计算设备，支持4-7人同时低延迟交互。通过完全离线的模型部署，LANChat确保敏感数据无需上传至云端，彻底杜绝外部泄露风险，确保金融交易、科研机密、企业战略等敏感对话数据无需上传至云端，从根本上杜绝外部泄露风险，为您提供安全与效率兼备的AI对话能力。
> LANChat：安全与智能，无需妥协。
